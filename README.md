# 🍽️ Chadia's Recipe Book

A beautiful Levantine recipe collection — installable as an iPhone app.

---

## 📱 How to Install on iPhone (one-time setup)

### Step 1 — Upload to GitHub Pages

1. Go to [github.com](https://github.com) and sign in
2. Click the **+** button (top right) → **New repository**
3. Name it exactly: `chadia-recipe-book`
4. Set to **Public**
5. Click **Create repository**
6. Click **uploading an existing file**
7. Drag ALL these files and the `icons` folder into the upload area:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icons/` (the whole folder)
8. Click **Commit changes**

### Step 2 — Enable GitHub Pages

1. In your repository, click **Settings**
2. Click **Pages** (left sidebar)
3. Under "Branch" select **main** → folder **/ (root)**
4. Click **Save**
5. Wait ~60 seconds, then your app is live at:
   `https://YOUR-GITHUB-USERNAME.github.io/chadia-recipe-book/`

### Step 3 — Install on iPhone

1. Open **Safari** on your iPhone (must be Safari, not Chrome)
2. Go to your GitHub Pages URL above
3. Tap the **Share** button (box with arrow pointing up)
4. Scroll down and tap **"Add to Home Screen"**
5. Tap **Add**

✅ Done! Chadia's Recipe Book is now on your iPhone home screen like a real app.

## ✨ Features

- 12 authentic Levantine recipes built-in
- Works fully offline after first load
- AI nutrition facts (requires WiFi)
- Add, edit, and save your own recipes
- Search, filter by category, favorites
- Cook mode with step-by-step timer
- Meal planner & shopping list
- Beautiful Arabic names for every recipe

---

## 🔄 Updating the App

To update recipes or fix something:
1. Replace `index.html` in your GitHub repository
2. The app will automatically update next time it's opened on WiFi
